# Privacy policy

Last updated: November 2026

ChecklistApp is a private, non-commercial app on one kitchen display.

## Google data the app uses

When a user connects their Google account, ChecklistApp asks for:

- **Google Calendar, read only:** to show today's and tomorrow's appointments from the calendars the user chooses, and to show recurring events (such as a timetable) next to routine items.
- **Google Tasks:** to show the user's tasks from the task lists they choose, and to mark a task as done, or as not done again, when it is ticked on the display.

The app never creates, changes or deletes calendar events. It changes tasks only by marking them done or not done.

## Where the data stays

All data stays on the display device. Appointments and tasks are kept there so the display also works offline. The sign-in tokens are stored in the device's keyring. Appointments and tasks are shown on the display, so anyone near it can see them.

The app has no server of its own. It sends data only to Google's own services, to read calendars and tasks and to mark tasks. There is no analytics, no advertising and no sharing with anyone else.

## Limited use

ChecklistApp's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. Google user data is never sold or transferred to anyone.

## Removing access and data

Disconnecting a user in the app removes their tokens and their stored Google data from the device. You can also revoke the app's access at any time at <https://myaccount.google.com/permissions>.
